
# Izakaya - Ordenes en Línea

Este programa funciona para visualizar el menú del bar, realizar ordenes, ver el subtotal, calcular la propina y ver la factura total del pedido.

## Autor

- Ximena Argüello [@anemix-x] (https://github.com/anemix-x) 


## Características

- Ver el menú del bar con precios.
- Realizar órdenes directamente llamándolas por nombre y solicitando la cantidad con un número entero.
- Ver la orden actual con el subtotal a pagar.
- Finalizar la compra, agregando una propina del 0 al 100 que se convierte en colones automáticamente.
- Salir del programa sin ordenar nada.


## Funcionamiento
Escribir su nombre y seleccionar entre las opciones del 1-4 en el menú.
- Los productos del menú de alimentos se pueden escribir en mayúscula o minúscula pero deben estar bien escritos.
- La cantidad de productos debe ser un número entero positivo y debe usar los números del teclado, no letras.
- Los precios aparecen en colones.
- Las propinas pueden ser números decimales, mayores a 0 y hasta 100, se deben escribir usando los números del teclado, no letras y tomando en cuenta que es el porcentaje y no el monto final.


## Requisitos Técnicos

Uso de diccionarios, bucles for y while, sentencias break, estructuras for/else/if/elif, f-strings, :.2f para decimales, enumerate, .append y .keys y .lower para el menú.
